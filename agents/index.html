Agent 01Research & Design AgentNiche validation · Product spec · Design brief
research-design.prompt.md

Validates buyer demand on Etsy, defines the product gap, sizes the product, and outputs a Design Brief with exact color and typography specs the Build Agent can execute without clarification.

Input
  • Product idea or topic
  • Target audience
  • Optional: competitor URL
Output
  • Demand signals + gap
  • PRODUCT SPEC block
  • DESIGN BRIEF block
  • Handoff note
Handoff: "Ready for Build Agent — [title], [pages], [format]. Gap: [one sentence]."
Agent 02Build AgentPage map · Full content scaffold · Component application
build.prompt.md

Assembles every page from the Design Brief — headings, body copy, fillable fields, callout boxes, tables, checklists, prompt blocks. Outputs content ready for Canva, Word, or Acrobat layout.

Input
  • PRODUCT SPEC block
  • DESIGN BRIEF block
Output
  • PAGE MAP (numbered)
  • Per-page content scaffold
  • Cover copy block
  • Disclaimer page (verbatim)
  • Fillable fields — spec'd
  • Navy table header
  • Gold callout border
  • Courier prompt blocks
  • Disclaimer last page
Handoff: "Build complete — [title], [N] pages, [format]. Ready for QA or Optimize Agent."
Agent 03Optimize AgentTitle SEO · Description clarity · Value perception · Pricing
optimize.prompt.md

Reviews any existing listing, scaffold, or cover copy and returns prioritized improvements. Five checks: title SEO, description clarity, value perception score, price positioning, thumbnail copy.

Input
  • Etsy listing
  • OR product page map
  • OR cover copy
  • Price + page count
Output
  • Revised title
  • BEFORE / AFTER diffs
  • Value scorecard
  • TOP 3 OPTIMIZATIONS
Priority: Clarity → Specificity → Trust → SEO → Visual
Agent 04QA AgentUsability · Voice · Visual · Flow · Disclaimer
qa.prompt.md

Simulates an overwhelmed buyer opening cold. Six test suites — first-30-seconds, field completeness, voice audit, visual consistency, logical flow, disclaimer verification — returns a numbered defect log.

Input
  • Content scaffold
  • OR page-by-page description
Output
  • 6-suite test report
  • Numbered defect log
  • ✅ PASSED / 🔁 REVISIONS
  • First-30-seconds test
  • Field completeness
  • Voice & tone audit
  • Visual consistency
  • Logical flow test
  • Disclaimer verification
Escalation: Any disclaimer defect or 5+ critical defects → back to Build Agent. No exceptions.
Agent 05Launch Check AgentBrand · Content · Legal · SEO · File integrity
launch-check.prompt.md

Final gate before any product goes live. Five checklist sections — brand compliance, content completeness, legal & disclaimers, listing SEO, file integrity — binary verdict: CLEAR or BLOCKED.

Input (all required)
  • Product title + description
  • File list + badge list
  • Price, pages, thumbnail
Output
  • 5-section pass/fail
  • Blocked items list
  • Advisory log
  • ✅ CLEAR / 🚫 BLOCKED
Hard rule: Any single Section C (legal) failure = automatic BLOCKED, no exceptions.
Agent 06Marketing AgentEtsy listing · Email · Pinterest · Social · Bundle · Newsletter
marketing.prompt.md

Writes every word a buyer sees before opening the product. Six output modes: Etsy listing (title + description + 13 tags), email sequence, Pinterest pin, social caption, bundle strategy, newsletter block.

Input
  • PRODUCT SPEC block
  • Output type (1–6)
Output modes
  • Etsy listing + 13 tags
  • Email sequence
  • Pinterest pin
  • Social caption
  • Bundle strategy
  • Newsletter block
  • Primary keyword first 40 chars
  • No urgency bait
  • Disclaimer in description
  • All 13 Etsy tags filled
Handoff: "Marketing copy complete — [title], [outputs]. Ready for Launch Check or direct publishing."
