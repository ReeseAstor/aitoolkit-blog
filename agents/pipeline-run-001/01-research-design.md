### 1.2 Competitor Audit

Pattern 1 — Title: Most use "Content Planner Printable" without a format
  specifier. Thumbnails are pastel/feminine. Price range $3–$7.

Pattern 2 — Structure: Single-sheet monthly calendar. No workflow sections,
  no batch logic, no prompt blocks. Buyer reviews frequently say
  "I wish it had more space to plan each piece end-to-end."

Pattern 3 — No sample fills. Buyers ask in 1-star reviews: "I couldn't
  figure out how to start." No Quick-Start page exists in top listings.

**Gap identified:** No fillable planner shows a complete content workflow
  (idea → draft → publish → repurpose) for a full month with prompt blocks
  and a batch day structure. Buyers want a system, not a calendar.

### 1.3 Buyer Moment

Buyer moment: It's Sunday night and they have a whole week of content to
  create but no plan, just a folder of half-formed ideas and mounting guilt.
  They want something to open right now that tells them exactly what to do
  first, what to batch together, and when to stop.

## STAGE 2 · PRODUCT SPEC

PRODUCT SPEC
─────────────────────────────────────────
Title slug     : Panic-Proof Content Batch Planner — Fillable PDF for Content Creators
Format         : Fillable PDF (primary) + Printable PDF (bonus)
Page count     : 32–36 pages
Primary use    : Plan, batch, and publish 30 days of content without
                 starting from scratch every week.
Core sections  :
  - Quick-Start Guide (how to use this system in under 10 min)
  - Monthly Brain Dump (capture all ideas in one session)
  - Batch Day Planner (group content by type/platform)
  - Per-Piece Production Tracker (idea → script → record → edit → publish)
  - Weekly Review (what went out, what to repurpose)
  - Repurpose Router (map one piece to 3+ formats)
  - Prompt Block Library (30 AI prompt starters for content)
  - Monthly Recap & Next-Month Reset
Fillable fields:
  - Video/post title (per piece)
  - Platform selector (checkbox)
  - Hook field
  - CTA field
  - Status tracker (dropdown: Idea / Scripted / Recorded / Edited / Live)
  - Repurpose checkboxes (Blog / Email / Reel / Pin / Thread)
  - Batch day date + content type groupings
  - Monthly win + lesson fields
Sample included: Yes — January 2026 fully filled example project
                 (4 YouTube videos batched across 2 days, with hooks written)
Immediate-use  : Open the Quick-Start Guide (P2). Run the Brain Dump (P4)
                 for 10 minutes. Then go to Batch Day Planner (P6).
