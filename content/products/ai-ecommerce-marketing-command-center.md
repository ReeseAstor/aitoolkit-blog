## Part 1 — Copy.ai prompts (product copy & email)

### 1. SEO product title generator
```
Write 5 SEO-friendly product titles (max 70 characters each) for this product:
Product name: [NAME]
Category: [CATEGORY]
Core keyword: [KEYWORD]
Target buyer: [BUYER]
Make one title keyword-first, one benefit-first, one emotion-first, one question-based, and one comparison-based.
```

### 2. Amazon / Shopify bullet rewrite
```
Rewrite these product bullets to be benefit-led, scannable, and under 250 characters each.
Original bullets:
[BULLET 1]
[BULLET 2]
[BULLET 3]
Product: [NAME]
Target buyer: [BUYER]
Tone: [TONE]
```

### 3. Product description from spec sheet
```
Turn this product spec sheet into a 150-word product description formatted for a Shopify product page.
Specs:
[SPECS]
Target buyer: [BUYER]
Tone: [TONE]
Include: hook, key benefit, 2-3 feature/benefit pairs, and a soft CTA.
```

### 4. Category page intro
```
Write a 100-word category page intro for [CATEGORY NAME] that targets the keyword [KEYWORD].
Mention 3 related products without naming them directly. Tone: [TONE]. Include an H1 and a short meta description.
```

### 5. Abandoned-cart email sequence
```
Write a 3-email abandoned-cart sequence for [PRODUCT NAME].
Email 1 (30 min): friendly reminder, social proof.
Email 2 (24 hr): objection handler + FAQ.
Email 3 (72 hr): discount or scarcity close.
Tone: [TONE]. Keep each email under 120 words.
```

### 6. Post-purchase upsell email
```
Write a post-purchase email that recommends a complementary product ([UPSELL]) to a customer who bought [PRODUCT].
Subject line: curious, not salesy.
Body: 100 words, one CTA.
Tone: [TONE].
```

### 7. Win-back email
```
Write a win-back email for a customer who has not purchased in [TIME].
Subject line: make it feel like a check-in, not a promotion.
Body: acknowledge the gap, share one improvement or new product, single CTA.
Tone: [TONE].
```

### 8. SMS promo blast
```
Write 5 SMS promos (under 160 characters) for [OFFER] on [PRODUCT].
Each should sound human, use urgency, and include a short link placeholder [LINK].
```

### 9. Meta ad primary text
```
Write 5 Meta ad primary-text variants (under 125 characters each) for [PRODUCT].
Angle 1: problem/solution.
Angle 2: testimonial.
Angle 3: before/after.
Angle 4: how-it-works.
Angle 5: limited-time offer.
Tone: [TONE].
```

### 10. Google Shopping description
```
Write a 70-character and a 150-character Google Shopping description for [PRODUCT].
Lead with the highest-intent benefit. Include [KEYWORD].
```

## Part 5 — Workflow prompts (the 90-minute system)

### 22. Weekly ecommerce content sprint
```
Plan a 90-minute weekly ecommerce content sprint for my store.
Store: [STORE NAME]
Top 10 SKUs: [LIST]
Channels: [CHANNELS]
Assign tasks across Copy.ai, Canva, AdCreative.ai, and Synthesia. Output a timed agenda and who does what if I have a VA.

### 23. Monthly campaign calendar
```
Build a 4-week ecommerce marketing calendar for [MONTH].
Include: 1 product launch or promotion per week, 2 emails/week, 3 social posts/week, 1 ad creative refresh/week, 1 video/week.
Map each asset to the tool that produces it.
```

### 24. Creative refresh checklist prompt
```
Audit my store's creative assets. I have [NUMBER] products and run ads on [PLATFORMS].

## Part 7 — The 12 weekly production checklists

### Checklist 1 — Copy.ai weekly email + product copy batch
- [ ] Generate subject lines for 2 weekly emails.
- [ ] Write primary email bodies (under 300 words each).
- [ ] Refresh product descriptions for top 10 SKUs.
- [ ] Write 1 abandoned-cart email.
- [ ] Write 1 SMS promo.
- [ ] Export copy to CSV or doc for scheduling.

### Checklist 2 — Canva store visual refresh
- [ ] Update 1 hero image per hero product.
- [ ] Create 3 lifestyle mockups.
- [ ] Resize hero images for Instagram, Pinterest, and email.
- [ ] Refresh brand kit colors/fonts if needed.
- [ ] Export all images in WebP or PNG.

### Checklist 3 — AdCreative.ai paid creative refresh
- [ ] Choose 1-2 products to promote this week.
- [ ] Upload product image, logo, brand colors.
- [ ] Generate 10-20 ad variants.
- [ ] Filter for conversion score 70+.
- [ ] Export top 3-5 creatives per ad set.

### Checklist 4 — Synthesia video batch
- [ ] Pick 1 product for a 60-second explainer.
- [ ] Write script (140-150 words).
- [ ] Choose avatar and voice.
- [ ] Generate, review, and download MP4.
- [ ] Add to product page and pin to social.

### Checklist 5 — Weekly content sprint (90-minute agenda)
- [ ] 0-15 min: plan the week's promotions and top SKUs.
- [ ] 15-45 min: generate copy in Copy.ai.
- [ ] 45-65 min: create visuals in Canva.
- [ ] 65-80 min: generate ad variants in AdCreative.ai.
- [ ] 80-90 min: queue everything in scheduler / ad manager.

### Checklist 6 — Product launch checklist
- [ ] Finalize product name and SKU.
- [ ] Write SEO product title, bullets, description.
- [ ] Design hero image + 3 mockups.
- [ ] Record 60-second explainer video.
- [ ] Build launch email sequence (3 emails).
- [ ] Create 5 social posts.
- [ ] Generate 8-10 ad creatives.
- [ ] Set up tracking links.

### Checklist 7 — Seasonal sale checklist
- [ ] Choose sale dates and discount.
- [ ] Update product pages with sale messaging.
- [ ] Design sale hero images and banners.
- [ ] Write sale email sequence (announce, last-chance, extended?).
- [ ] Generate 12+ ad creatives.
- [ ] Schedule social countdown posts.

### Checklist 8 — Email list growth kit
- [ ] Create lead magnet (checklist, guide, or discount).
- [ ] Build landing page copy with Copy.ai.
- [ ] Design lead-magnet mockup in Canva.
- [ ] Write welcome sequence (3 emails).
- [ ] Generate lead-gen ad variants in AdCreative.ai.

### Checklist 9 — Review mining → creative
- [ ] Export 20-50 recent reviews.
- [ ] Identify top 5 phrases/themes.
- [ ] Turn themes into ad angles in Copy.ai.
- [ ] Design testimonial-style graphics in Canva.
- [ ] Build retargeting creatives in AdCreative.ai.

### Checklist 10 — International expansion creative kit
- [ ] Select 1-2 target markets/languages.
- [ ] Localize product copy with Copy.ai.
- [ ] Adapt visuals for local preferences in Canva.
- [ ] Generate localized video scripts for Synthesia.
- [ ] Build geo-targeted ad variants.

### Checklist 11 — Retention / loyalty campaign
- [ ] Segment repeat customers.
- [ ] Write VIP early-access email.
- [ ] Design loyalty graphic in Canva.
- [ ] Generate 4 retargeting creatives.
- [ ] Plan referral or rewards mention.

### Checklist 12 — Monthly analytics + creative refresh
- [ ] Pull last month's ad, email, and store metrics.
- [ ] Identify top 3 performing products and angles.
- [ ] Refresh underperforming product pages.
- [ ] A/B test 2 new subject lines per email.
- [ ] Replace lowest-scoring ad creatives.
- [ ] Update top product videos if older than 90 days.

## How to use this system

1. Start with **Checklist 5** to plan your 90-minute sprint.
2. Open the tool-specific prompts in the order listed (copy first, then visuals, then ads, then video).
3. Fill in every bracketed placeholder with your store details.
4. Run the weekly cycle for 4 weeks, then use **Checklist 12** to audit and refresh.

The goal is not to use every prompt every week — it is to never start from a blank page again.
