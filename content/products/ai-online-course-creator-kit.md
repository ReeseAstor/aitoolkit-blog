## Module 1 — Validate & position the course (Copy.ai)

**Outcome:** A one-sentence promise, a named audience, and proof people will pay — before you build anything.

### Prompt 1.1 — The course promise generator
```
You are a course positioning strategist. My topic is [TOPIC]. My ideal student is
[WHO THEY ARE] and right now they struggle with [PAIN]. Write 10 one-sentence course
promises in the format: "Go from [BEFORE STATE] to [AFTER STATE] in [TIMEFRAME] —
without [BIGGEST OBJECTION]." Make them specific and outcome-driven, no fluff.
```

### Prompt 1.2 — Audience pain-point miner
```
List the 15 most painful, specific problems someone trying to [ACHIEVE OUTCOME]
faces. For each, write the exact words they'd type into Google or YouTube search.
Group them into Beginner, Intermediate, and Stuck.
```

### Prompt 1.3 — Pre-sell validation post
```
Write a 150-word social post that pre-sells my course [PROMISE] before it exists.
Goal: get replies/DMs from interested people. Include a soft CTA to comment a keyword.
Tone: helpful expert, not salesy.
```

### Template 1.A — Positioning one-pager
- **Course title (working):** ______
- **One-sentence promise:** ______
- **Who it's for (be specific):** ______
- **Who it's NOT for:** ______
- **The transformation:** From ______ → to ______
- **Proof I can teach this:** ______
- **Price hypothesis:** $______

## Module 2 — Outline & curriculum (Copy.ai)

**Outcome:** A complete module → lesson outline you could record tomorrow.

### Prompt 2.1 — Full curriculum builder
```
Act as an instructional designer. Build a complete curriculum for a course titled
[TITLE] that delivers this promise: [PROMISE]. Structure it as 5–7 modules, each with
3–5 lessons. For every lesson give: a title, the single learning objective, and the
one action the student takes. End with a capstone project. Keep each lesson scoped to
under 8 minutes of video.
```

### Prompt 2.2 — The "minimum viable course" cutter
```
Here is my curriculum: [PASTE]. I want to launch a lean V1 fast. Cut it to the 60%
that delivers 90% of the transformation. Tell me what to drop, what to keep, and what
to move to a future "advanced" upsell.
```

### Prompt 2.3 — Lesson-to-outcome audit
```
Review this outline: [PASTE]. For each lesson, flag any that don't directly move the
student toward [PROMISE]. Suggest a replacement lesson for each weak one.
```

### Template 2.A — Curriculum map
```
MODULE 1: [Name] — Outcome: ____
  1.1 [Lesson] — Objective: ____ — Action: ____
  1.2 ...
MODULE 2: ...
CAPSTONE: ____
```

## Module 3 — Write the lesson scripts (Copy.ai)

**Outcome:** Word-for-word scripts you can read on camera or paste into Synthesia.

### Prompt 3.1 — Lesson script writer
```
Write a video script for the lesson "[LESSON TITLE]". Learning objective: [OBJECTIVE].
Audience: [WHO]. Structure: (1) a 1-sentence hook that names the problem, (2) why it
matters, (3) the teaching in 3 clear steps with one example each, (4) the single action
to take now, (5) a one-line bridge to the next lesson. Target 700–900 words, spoken
tone, short sentences, no jargon. Mark [PAUSE] and [SHOW ON SLIDE: ...] cues.
```

### Prompt 3.2 — Hook punch-up
```
Here are my 5 lesson openers: [PASTE]. Rewrite each as a 1–2 sentence hook that makes
the student feel the cost of NOT knowing this. Curiosity over hype.
```

### Prompt 3.3 — Script-to-slide extractor
```
From this script: [PASTE], extract a slide outline: a title slide, 3–6 bullet slides
(max 6 words per bullet), and one summary slide. Output as plain text I can paste into
Canva.
```

### Template 3.A — Script block
```
LESSON: ____
HOOK: ____
WHY IT MATTERS: ____
STEP 1: ____  [SHOW ON SLIDE: ____]
STEP 2: ____
STEP 3: ____
DO THIS NOW: ____
NEXT: ____
```

## Module 4 — Produce video without a camera (Synthesia + Canva)

**Outcome:** Polished talking-head lessons and branded slides — zero filming.

### Workflow
1. Paste each script from Module 3 into **[Synthesia](https://synthesia.io/?via=aitoolkit)**, pick an avatar + voice, and let it render the talking-head video. Use the `[SHOW ON SLIDE]` cues to add on-screen text.
2. Build matching slides in **[Canva](https://canva.com/?via=aitoolkit)** from the Module 3 slide extracts. Use one template across all lessons for consistency.
3. Export and assemble in your course host (Teachable, Kajabi, Gumroad, or Podia).

### Prompt 4.1 — Synthesia scene breakdown
```
Convert this script into a Synthesia scene plan: split into scenes of 2–4 sentences,
and for each scene write the on-screen text (max 8 words) and a background suggestion.
Script: [PASTE]
```

### Prompt 4.2 — Canva slide copy
```
Write slide copy for a [N]-slide lesson deck on [TOPIC]. Per slide: a 3–5 word
headline and up to 3 bullets of max 6 words. Add speaker notes (1 sentence) per slide.
```

### Checklist 4.A — Per-lesson production
- [ ] Script finalized and proofread
- [ ] Synthesia video rendered (avatar + voice locked across course)
- [ ] Canva slides match brand colors + font
- [ ] Captions/subtitles on (accessibility + silent viewing)
- [ ] Lesson under 8 minutes
- [ ] Downloadable resource attached (worksheet/template)

## Module 5 — Audio version + workbook (Speechify + Canva)

**Outcome:** An audio track of every lesson (students love listening on the go) and a fill-in workbook that boosts completion.

### Prompt 5.1 — Audio script adaptation
```
Adapt this video script for audio-only listening (no "look at the slide" references).
Add verbal signposting like "the first thing is..." so it's clear without visuals.
Script: [PASTE]
```
Then narrate it with **[Speechify](https://speechify.com/?via=aitoolkit)** for a clean, natural audio version students can download.

### Prompt 5.2 — Workbook builder
```
Create a student workbook for the module "[MODULE]". For each lesson include: 1
key-takeaway summary, 2 reflection questions, and 1 action exercise with space to write.
Output as Markdown I can paste into Canva Docs.
```

### Template 5.A — Workbook page
```
LESSON: ____
KEY TAKEAWAY: ____
REFLECT: 1) ____  2) ____
DO: ____  (space for notes)
```

## Module 6 — Sales page, emails & launch (Copy.ai)

**Outcome:** A converting sales page, a 5-email launch sequence, and a checklist to ship.

### Prompt 6.1 — Sales page writer
```
Write a long-form sales page for my course [TITLE] ([PRICE]). Promise: [PROMISE].
Audience: [WHO]. Sections: headline + subhead, the problem, the cost of staying stuck,
the solution (this course), what's inside (module-by-module), who it's for / not for,
about me, pricing with a value stack, FAQ (6 questions), and a guarantee. Persuasive
but honest. No fake scarcity.
```

### Prompt 6.2 — 5-email launch sequence
```
Write a 5-email launch sequence for [COURSE] at [PRICE]. Email 1: announce + story.
Email 2: the transformation/what's inside. Email 3: objection-handling + FAQ.
Email 4: social proof / case study (leave placeholders). Email 5: last call + deadline.
Each under 200 words, one CTA each.
```

### Prompt 6.3 — Pricing & bonus stack
```
My course teaches [OUTCOME] and saves students [TIME/MONEY]. Suggest 3 price points
(lean, core, premium) with a justification for each, plus 3 bonus ideas that increase
perceived value without much extra work.
```

### Pricing quick-calculator
```
Target launch revenue = $______
Realistic conversion (email list × 2–5%) = ______ buyers
Price needed = Target ÷ buyers = $______
→ Round to a clean anchor ($X9 or $X7). Add an order bump (workbook+templates) at 30–40% of price.
```
