# AI ToolKit — Master Upload Checklist

All paths are relative to `content/products/`. Standalone products ship a single PDF; bundles ship a ZIP.
Catalog: **13 products**. Listing copy and social assets are drop-in ready in each product folder.

## How to use this checklist (per product)

1. **Create the Gumroad product** — paste the title + `*_listing-gumroad.md` copy, set the price, upload the `deliverable_file`, add the `preview_images`.
2. **Create the Etsy listing** — paste the `*_listing-etsy.md` copy (title/tags/description already formatted to Etsy limits), upload the same deliverable + previews.
3. **Copy the real checkout URLs** Gumroad/Etsy give you.
4. **Replace the placeholder URLs** in the product's `landing_page` HTML. Each page has `https://gumroad.com/l/<slug>` and `https://www.etsy.com/listing/<slug>` placeholders — swap both Gumroad and both Etsy CTA links (top + bottom).
5. **Commit & push** the landing-page edits so Vercel redeploys with live buy links.
6. **Post the launch assets** from `social_assets` (X thread + 2 video scripts + email blast).

> Tip: do the 9 standalone products first, then the 3 bundles (their ZIPs already contain the standalone PDFs), then prod-013.
