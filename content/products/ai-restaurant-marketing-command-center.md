## Part 1 — Copy.ai prompts (menu copy, social, and email)

### 1. Menu description upgrade
```

[ITEM 2: name + current description]
[ITEM 3: name + current description]

Restaurant style: [FINE DINING / CASUAL / FAST CASUAL / ETHNIC / CAFE]
Tone: [WARM / PLAYFUL / SOPHISTICATED / BOLD]
```

### 2. Daily specials social post
```

Today's specials:
1. [SPECIAL 1]
2. [SPECIAL 2]
3. [SPECIAL 3]

Include: a hook in the first line, a short sensory description of each special, a local reference (mention the neighborhood or a local landmark), and a CTA to reserve or walk in. Add 5 relevant hashtags. Max 150 words.
```

```

[DISH 1]
[DISH 2]
[DISH 3]
```

```
Menu sections:
1. [STARTERS / APPETIZERS]
2. [MAINS]
3. [SIDES]
4. [DESSERTS]
5. [DRINKS]

Design instructions:
- Clean hierarchy: section headers > dish names > descriptions
- Price alignment: right-aligned, same font size as dish name
- No food photos on the menu (research shows they reduce perceived quality)
- White space between sections
- Font: [SERIF for fine dining / SANS-SERIF for casual]
```

## Part 6 — The 12 Weekly Production Checklists

### Checklist 1: Monday — Menu & Copy Refresh
- [ ] Verify menu on website reflects current prices and items
- [ ] Confirm daily specials for the week are set with kitchen
- [ ] Generate 5 menu description upgrades (Prompt #1)
- [ ] Write daily specials social posts for Mon-Fri (Prompt #2)
- [ ] Update delivery platform descriptions if changed (Prompt #13)
- [ ] Check Google Business Profile for accuracy (hours, menu link, photos)
- [ ] Time budget: 20 minutes

### Checklist 2: Tuesday — Social Media Content
- [ ] Post daily special (Prompt #2)
- [ ] Post 1 Instagram Story (Checklist: Story template)
- [ ] Engage with 5 local food accounts / customer tags
- [ ] Respond to all social DMs and comments
- [ ] Check competitor social for content gaps
- [ ] Time budget: 25 minutes

### Checklist 3: Wednesday — Visual Assets
- [ ] Design or update 3 menu items in Canva menu template (Prompt #26)
- [ ] Create 2 Instagram post graphics (Prompt #27)
- [ ] Prepare 1 flyer or promo graphic if event this week (Prompt #28)
- [ ] Export all assets in correct formats (IG: 1080x1080, Story: 1080x1920)
- [ ] Time budget: 20 minutes

### Checklist 4: Thursday — Email Newsletter
- [ ] Draft weekly newsletter (Prompt #15)
- [ ] Pull 3 specials from Monday's batch
- [ ] Write "From the Kitchen" chef note (2-3 sentences)
- [ ] Add upcoming event CTA if applicable
- [ ] Test send to self; check on mobile
- [ ] Schedule send for Friday 11 AM
- [ ] Time budget: 15 minutes

### Checklist 5: Friday — Paid Ads Review
- [ ] Check active Meta ads performance (CTR, CPC, conversions)
- [ ] Pause underperforming creatives (below [X] CTR)
- [ ] Generate 3 new ad variations if needed (Prompt #31)
- [ ] Review Google Search ad positions for target keywords
- [ ] Set weekend budget pacing
- [ ] Time budget: 15 minutes

### Checklist 6: Saturday — Weekend Content Prep
- [ ] Schedule weekend posts (2 per day minimum)
- [ ] Prepare weekend Story templates (behind-the-scenes, busy night)
- [ ] Confirm reservation page is live and booking widget works
- [ ] Set phone notification for urgent review response
- [ ] Time budget: 10 minutes

### Checklist 7: Sunday — Review & Analytics
- [ ] Read and respond to all week's reviews (Prompt #12)
- [ ] Log week's metrics: covers, revenue, online orders, social engagement
- [ ] Identify top-performing post (replicate next week)
- [ ] Identify bottom-performing post (don't repeat)
- [ ] Plan next week's theme (seasonal, event, or community focus)
- [ ] Time budget: 20 minutes

### Checklist 8: Monthly — SEO & Content
- [ ] Run Google Business Profile audit (Prompt #37)
- [ ] Publish 1 neighborhood dining or behind-the-scenes blog post (Prompt #36)
- [ ] Update GBP photos (add 5 new: dishes, events, team)
- [ ] Check Google Search ranking for [TARGET KEYWORD]
- [ ] Review and update Surfer content audit for blog
- [ ] Time budget: 45 minutes

### Checklist 9: Monthly — Video Content
- [ ] Produce 1 chef intro / story video (Prompt #34) — quarterly cadence
- [ ] Produce 1 seasonal promo video (Prompt #35) — monthly
- [ ] Post video to Instagram Reels, TikTok, YouTube Shorts
- [ ] Embed video on website homepage or about page
- [ ] Time budget: 30 minutes (script + generate; rendering is background)

### Checklist 10: Seasonal — Menu Launch
- [ ] Write full seasonal menu descriptions (Prompt #22)
- [ ] Design updated menu in Canva (Prompt #26)
- [ ] Write seasonal launch email (Prompt #3)
- [ ] Create 3 social announcement posts (Prompt #11)
- [ ] Produce seasonal promo video (Prompt #35)
- [ ] Update website menu page and PDF
- [ ] Update delivery platform menus
- [ ] Update GBP menu link and photos
- [ ] Time budget: 90 minutes (one-time, 4x per year)

### Checklist 11: Event-Specific — Catering & Private Dining
- [ ] Review catering inquiry pipeline (email + form)
- [ ] Send proposal emails within 24 hours (Prompt #4)
- [ ] Update private dining page seasonally (Prompt #9)
- [ ] Create 1 catering promotion social post per month
- [ ] Follow up on proposals older than 5 business days
- [ ] Time budget: 15 minutes weekly

### Checklist 12: Quarterly — Brand & Partnership
- [ ] Review Instagram bio and update if stale (Prompt #24)
- [ ] Audit all delivery platform listings for consistency (Prompt #13)
- [ ] Review and respond to all unanswered Google/Yelp reviews (Prompt #12)
