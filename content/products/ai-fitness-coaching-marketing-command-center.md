## Part 6 — Cross-Tool Workflows (The 90-Minute Weekly System)

### 29. Monday: Content batch day (Copy.ai + Canva)
```
WEEKLY WORKFLOW — MONDAY (45 minutes)

Step 1 (15 min): Open Copy.ai. Use Prompt #1 (Weekly Social Caption Batch).
- Input this week's programming theme: [THEME]
- Generate 7 captions
- Edit for voice (2 min per caption)
- Schedule in [SCHEDULING TOOL: e.g., Later / Buffer / Meta Business Suite]

Step 2 (15 min): Open Canva. Use Prompt #9 (Workout Card Template).
- Create this week's workout card graphic
- Create 2 quote/testimonial graphics (Prompt #12)
- Export all as PNG
- Attach to scheduled posts

Step 3 (10 min): Open Copy.ai. Use Prompt #2 or #5 (Email / Check-in).
- Write this week's client email or check-in response
- Queue in email platform

Step 4 (5 min): Review the week's content calendar.
- Confirm all 7 posts are scheduled
- Confirm email is queued
- Note any client events (PRs, milestones) to celebrate mid-week

OUTPUT: 7 social posts + 3 graphics + 1 email = DONE.
```

### 30. Wednesday: Video day (Synthesia)
```
WEEKLY WORKFLOW — WEDNESDAY (20 minutes)

Step 1 (5 min): Choose this week's video topic.
- Rotate: Exercise tutorial / Client tip / Program update / FAQ answer
- Use Prompt #16 (Exercise Tutorial) or #18 (Monthly Recap)

Step 2 (10 min): Generate in Synthesia.

Step 3 (5 min): Distribute.
- Post to Instagram Reels / YouTube Shorts / TikTok
- Embed in client app or email
- Save to "Video Library" for future client onboarding

OUTPUT: 1 professional video = DONE.
```

### 31. Friday: Ads + audio day (AdCreative.ai + Speechify)
```
WEEKLY WORKFLOW — FRIDAY (25 minutes)

Step 1 (10 min): AdCreative.ai — Refresh ad creatives.
- Check current ad performance (CTR, CPL)
- If CTR < 1%: Use Prompt #20 or #24 to generate 2 new creatives
- If performing well: Leave running, increase budget 10%
- Pause any ad with CPL > [TARGET: e.g., $15]

Step 2 (10 min): Speechify — Create one audio asset.
- Rotate: Audio workout / Nutrition guide / Newsletter audio
- Use Prompt #25, #26, or #28
- Generate and review
- Upload to client app / private podcast feed / email
```
