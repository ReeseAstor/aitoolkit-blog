## Part 1 — Citation audit prompts (10 prompts)

### 1. Baseline visibility check — ChatGPT
```
Act as a buyer in my market. Ask me nothing; instead, answer this question
the way ChatGPT typically would: [BUYER QUESTION, e.g. "what's the best CRM
for a 10-person real estate team?"]. Then list: (1) which brands you named
and in what order, (2) what descriptive language you used about each,
(3) which sources or page types you drew from, (4) what a brand would need
on its website to earn a citation in an answer like this.
My brand: [BRAND]. My category: [CATEGORY]. My site: [URL].
```

### 2. Cross-engine comparison audit
```
I will ask the same buyer question across ChatGPT, Perplexity, and Gemini.
Question: [BUYER QUESTION]. My brand: [BRAND]. Competitors: [COMPETITOR 1,
COMPETITOR 2, COMPETITOR 3].
Generate a comparison worksheet: for each engine, columns for — was my brand
named (Y/N), position in answer, sentiment of description, which competitors
were named, which source pages were cited. Then write 3 hypotheses for why
Perplexity results differ from ChatGPT results for the same question, given
that Perplexity runs live search and cites 5-10 sources per answer.
```

### 3. Competitor citation teardown
```
Here are the pages an AI engine cited when answering [BUYER QUESTION]:
[PASTE 3-5 CITED URLS].
For each page, analyze: (1) how the page opens — definition, story, or
sales pitch? (2) how many statistics, named sources, and direct quotes it
contains, (3) whether it has a visible publish/update date, (4) whether it
answers the question in a self-contained extractable block.
Output a table, then list the 5 structural elements my page [MY URL] is
missing that all cited pages share.
```

### 4. Prompt-portfolio builder
```
Build my tracking prompt portfolio. My business: [BUSINESS TYPE]. My
customers ask questions like [3 EXAMPLE QUESTIONS]. Generate 25 buyer-style
prompts in 5 buckets: best-of comparisons ("best [CATEGORY] for [USE CASE]"),
alternatives ("[COMPETITOR] alternatives"), problem-solution ("how do I fix
[PROBLEM]"), pricing ("how much does [SOLUTION] cost"), and definition
("what is [TERM]"). Each prompt phrased the way a real buyer would type it,
not the way a marketer would. Group by engine suitability: which of these
would trigger live search in Perplexity vs draw on ChatGPT training data.
```

### 5. Sentiment and description audit
```
When AI engines describe my brand, this is the language they use:
[PASTE 3-5 REAL ENGINE DESCRIPTIONS FROM YOUR MANUAL CHECKS].
My intended positioning: [INTENDED POSITIONING].
Rewrite each engine description to match my intended positioning, then
produce a "description correction plan": the 3 on-page changes (About page
language, homepage definition block, schema sameAs links) most likely to
make engines adopt my wording. Explain for each change why engines are
likely to adopt it — engines inherit language from consistent,
well-structured, widely repeated sources.
```

### 6. Overlap gap analysis
```
Research shows only 11% of cited domains overlap between ChatGPT and
Perplexity. My site was cited in [ENGINE A] for [QUERY A] but not in
[ENGINE B] for [QUERY B]. My page: [PASTE PAGE TEXT, first 500 words].
Diagnose: (1) what the live-search engines (Perplexity, AI Overviews) need
that my page may lack — crawlability, date stamp, clean answer block;
(2) what the training-data engines (ChatGPT, Gemini) need — repetition
across authoritative third-party sources, definition clarity; (3) produce
a prioritized fix list with the single highest-impact change first.
```

### 7. Zero-citation diagnostic
```
My brand has never been cited for any of my 25 tracking prompts:
[PASTE PORTFOLIO]. My site: [URL]. My content inventory: [LIST TOP 10 PAGES
AND POST DATES].
Diagnose in this order: (1) crawlability — can ChatGPT's crawler and Bing
access my key pages, or are they gated/blocked in robots.txt? (2) freshness
— is my newest visible date older than 6 months? (3) extractability — does
any page open with a direct 40-60 word answer to a buyer question?
(4) entity clarity — do engines know what my brand IS (schema, consistent
descriptions)? Output: the one blocking failure I should fix this week.
```

### 8. Agency client audit report
```
I ran a manual citation audit for a client. Client: [CLIENT]. Category:
[CATEGORY]. Results across 25 prompts in ChatGPT, Perplexity, and Gemini:
[PASTE RESULTS — brand named X/25, competitors named Y/25].
Write a client-ready 1-page audit summary: baseline citation share, top 3

overpromising. The client has [BUDGET TIER: under $50/mo / $80-100/mo /
```

## Part 2 — Extractable structure prompts (10 prompts)

### 11. Definition-first page rewrite
```
Rewrite the opening of this page so an AI engine can extract a clean
definition. Requirements: first sentence is a direct definition of
[TERM/SERVICE] in under 40 words; second sentence adds the differentiator;
no marketing adjectives in the first paragraph; include the current date
in a "Last updated" line; keep my brand name attached to the definition.
Current opening: [PASTE CURRENT OPENING].
My brand: [BRAND]. What we do: [ONE-SENTENCE DESCRIPTION].
```

### 12. Extractable answer block
```
Add a 50-70 word self-contained answer block to the top of this page —
the exact passage an AI engine could quote verbatim when asked
[BUYER QUESTION]. Rules: no pronouns without antecedents, name the brand
once, include one hard number, no bullet points inside the block.
Page text: [PASTE PAGE TEXT].
```

### 13. Dated FAQ section
```
Write a 6-question FAQ section for this page, every question phrased the
way a buyer would type it into ChatGPT or Perplexity: [PASTE PAGE SUMMARY].
Rules: each answer under 60 words, self-contained, at least 3 answers
contain a statistic or named source, include "Last updated: [MONTH YEAR]"
in the section header, no questions the page cannot answer truthfully.
```

### 14. Schema markup generator
```
Generate JSON-LD schema for my [PAGE TYPE: homepage / service page /
FAQ page / product page]. Business: [NAME]. What we do: [DESCRIPTION].
URL: [URL]. Same-as profiles: [LIST SOCIAL/LISTING URLS].
Include: Organization (or LocalBusiness) block with name, description,
url, sameAs array; FAQPage block if this page has an FAQ; dateModified
set to [DATE]. Output valid JSON-LD only, no commentary.
```

### 15. Crawlability pre-flight check
```
Here is my robots.txt and the URL list of my 10 most important pages:
[PASTE ROBOTS.TXT + URL LIST].
Check: (1) does anything block GPTBot, ChatGPT-User, PerplexityBot, or
Google-Extended? (2) are any key pages behind a paywall, login, or JS-only
render that would make them invisible to crawlers? (3) output a fix list:
exact robots.txt lines to change, pages to open up, and the one-line meta
robots tag each key page should carry. Pages an AI crawler cannot access
cannot be cited.
```

### 16. Snippet-to-citation conversion
```
This page already wins Google featured snippets for [QUERY]:
[PASTE SNIPPET TEXT + PAGE URL].
Convert it into an AI-citation machine: keep the snippet passage, add a
dated "Last updated" line, add a 6-question FAQ, add one original statistic
or named-source citation the page currently lacks, and draft a 60-word
extractable answer block that quotes the snippet nearly verbatim. Engines
already trust this page for the query — the goal is making the same passage
trivially extractable.
```

### 17. Perplexity-source formatting
```
Perplexity runs live search and cites 5-10 sources per answer. Reformat
this article so each section is independently citable: [PASTE ARTICLE].
Rules: every section gets an H2 phrased as a buyer question, the first
sentence under each H2 is a complete standalone answer, add a sources line
at the end naming [2-3 REAL SOURCES YOU USED], keep total length under
1,200 words so the live crawl stays focused.
```

### 18. AI Overviews trigger page
```
Google AI Overviews trigger on roughly half of tracked queries and
synthesize from the traditional index. Rebuild this page to be
Overview-friendly: [PASTE PAGE]. Structure: a direct answer paragraph
under 60 words immediately after the H1, a dated FAQ, one comparison table
with clean column headers, authoritative outbound citations to
[2-3 NAMED SOURCES], and schema markup. Remove any content that buries
the answer below 800 words of intro.
```

### 19. Entity consistency sweep
```
Audit my brand's entity consistency across these descriptions:
[PASTE: HOMEPAGE META DESCRIPTION, ABOUT PAGE FIRST PARAGRAPH, GOOGLE
BUSINESS PROFILE DESCRIPTION, LINKEDIN COMPANY TAGLINE].
Engines inherit language from repeated, consistent sources. Rewrite all
four to share one canonical sentence describing what [BRAND] does, for
whom, with what differentiator — while keeping each channel's natural tone.
Output: the canonical sentence, then the four adapted versions.
```

### 20. Page-level GEO scorecard
```
Score this page for GEO extractability, 10 points each, with a fix list:
[PASTE PAGE]. Criteria: definition-first opening (0-10), self-contained
answer block (0-10), dated FAQ (0-10), fact density — statistics, named
sources, quotes (0-10), visible freshness date (0-10), schema markup
(0-10), crawlability — no gating (0-10), entity clarity — brand described
consistently (0-10). Output the score table, then the 3 fixes with the
highest score-per-hour-of-work ratio.
```

## The 10 production checklists

### Checklist 1 — Monday baseline check (15 min, weekly)
- [ ] Paste each of my 5 tracking prompts into ChatGPT
- [ ] Same 5 into Perplexity (live search — most generous citer)
- [ ] Same 5 into Gemini
- [ ] Log: brand named Y/N, position, sentiment, competitors named
- [ ] Note any new citation and which page earned it
- [ ] Update the citation log spreadsheet

### Checklist 2 — Page extractability pass (per page, 30 min)
- [ ] First sentence under H1 is a direct definition under 40 words
- [ ] 50-70 word self-contained answer block near the top
- [ ] No marketing adjectives in the first paragraph
- [ ] Brand name appears in the extractable passage
- [ ] One hard number in the extractable passage

### Checklist 3 — Dated FAQ build (per page, 20 min)
- [ ] 6 questions phrased as buyers actually type them
- [ ] Every answer under 60 words
- [ ] At least 3 answers contain a statistic or named source
- [ ] "Last updated: [MONTH YEAR]" visible on the page
- [ ] FAQPage schema added

### Checklist 4 — Fact density (per asset, 20 min)
- [ ] At least one statistic per 150 words (money pages) / 300 words (support pages)
- [ ] Every statistic has a named source inline
- [ ] One expert quote with attribution
- [ ] One original statistic from my own data where possible
- [ ] Zero invented numbers — every [SOURCE NEEDED] tag resolved

### Checklist 5 — Crawlability pre-flight (monthly + after site changes)
- [ ] robots.txt does not block GPTBot, ChatGPT-User, PerplexityBot, or Google-Extended
- [ ] Key pages not behind paywall, login, or JS-only rendering
- [ ] Sitemap submitted and current
- [ ] Schema validates (Rich Results Test / validator.schema.org)
- [ ] Canonical tags correct on refreshed pages

### Checklist 6 — Freshness signals (per asset)
- [ ] "2026" in title where natural
- [ ] Visible "Last updated" date under the H1
- [ ] All visible dates current
- [ ] Statistics older than 12 months replaced or re-sourced
- [ ] One new section noting what changed in the last year

### Checklist 7 — Per-engine structure (per asset)
- [ ] Perplexity: sections phrased as buyer-question H2s, sources line included
- [ ] AI Overviews: direct answer paragraph within 60 words of H1
- [ ] ChatGPT/Gemini (training data): definition passage consistent with About page and third-party descriptions
- [ ] Page opens correctly when fetched without JS

### Checklist 8 — Weekly citable asset ship (90 min, weekly)
- [ ] Asset picked from 12-week calendar
- [ ] Drafted with prompts P31-P34, facts verified
- [ ] Structure pass done (Checklist 2 + 3)
- [ ] Published, sitemap updated, Search Console indexing requested
- [ ] One live Perplexity check for the asset's target question
- [ ] Logged in citation log

### Checklist 9 — Tool tier decision (monthly, 10 min)
- [ ] Citation share computed for the month
- [ ] Rule applied: rising share → stay manual + Copy.ai ($24/mo billed annually)
- [ ] Flat or falling 30+ days → trial Writesonic Starter ($79/mo billed annually) or Surfer Standard ($99/mo billed yearly)
- [ ] Existing Surfer team needing multi-engine → compare Surfer Pro ($182/mo billed yearly) vs Writesonic Growth
- [ ] Agency/enterprise share-of-voice defense → shortlist Profound, Otterly.ai, Peec AI
- [ ] Decision + date logged

### Checklist 10 — Quarterly review (45 min, quarterly)
- [ ] Citation share trend by engine
